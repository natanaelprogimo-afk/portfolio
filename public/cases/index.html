01 / AGENT SYSTEMS / BACKEND

AI Automation Factory

Private repository · Development

An independently developed system for designing, operating and evaluating AI-enabled workflows with controlled access to tools and human review of risky actions.

CONCEPTUAL ARCHITECTURE · NOT A SCREENSHOT
React UIFastAPIAgent runtimePostgres / Redis

Engineering problem

Agent workflows can execute actions with side effects. Production-oriented design requires authorization boundaries, safe retries, execution limits, traceability and explicit human approval where appropriate.

Implementation scope

  • API and dashboard for agents, execution state and approvals.
  • Execution cost and token limits.
  • Idempotency keys to avoid duplicate actions on retry.
  • Rate limiting, structured workflow state and test coverage.

Trade-offs & limits

  • Human approval takes precedence over unrestricted autonomy.
  • Uncertain failed requests are not automatically retried.
  • Private README and tests describe implementation; no production SLA or customer adoption is claimed.
  • Live services and secrets remain private.

03 / STRUCTURED DATA / COMPARISON

Catalog Integrity Engine

Private internal prototype

A data-comparison workflow exploring mismatches between product feeds and observed catalog records, with explicit output states for discrepancies.

CONCEPTUAL ARCHITECTURE · NOT A SCREENSHOT
FeedNormalizeCompareResults

Engineering problem

Price and product attributes can diverge across data sources. Comparisons need deterministic keys, consistent numeric interpretation, clear failure classifications and useful audit output.

Engineering focus

  • Comparison of expected and observed fields.
  • Match/mismatch result structures and sample-run validation.
  • Prototype integration experiments with external workflow tools.

Evidence & limitations

  • The original private source is not linked publicly.
  • Controlled sample runs do not demonstrate paid deployments or customer adoption.
  • The linked lab is a new independent implementation of the comparison idea.
