Three small, working engineering exercises built for technical review. Edit the sample data and observe the output. All computation happens inside your browser; no data is sent to any server.

Transparency: These are independently implemented public teaching demonstrations inspired by common engineering problems. They are not screenshots, instances or extracts of private VYRA products, nor evidence of production customer usage. The source and tests live in the public portfolio repository.

Catalog reconciliation

Compare two CSV datasets by SKU, with cent-precision price normalization and explicit match, mismatch, missing, and extra categories. Includes quote handling and duplicate-key rejection.

Local-only · no API calls

Press Compare catalogs to execute.

Idempotent request behavior

Simulate how a service might handle an idempotency key. Replaying the same key and payload returns the recorded result, while key collisions and uncertain failures produce a conflict. This is an in-memory example, not an HTTP server.

Submit the same key twice to see replay behavior.

Operational metrics aggregation

Validate structured JSON events and compute daily request counts, error counts, success rate, and mean response latency. Input validation includes maximum sizes and required fields.

A working aggregation, not a SQL engine

Press Analyze events to execute.
