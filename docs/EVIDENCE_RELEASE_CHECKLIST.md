# Verified evidence release checklist — Alerson Morales

The public portfolio is already deployed. The following items would increase trust **after** collecting genuine source evidence.

## 1. Real product screenshots

For each private product candidate (AI Automation Factory, VYRA Fitness, Catalog Integrity Engine):

- [ ] Choose a screen from a working application or a controlled locally deployed environment, not a mockup.
- [ ] Remove API keys, emails, phone numbers, private domain names, real account identifiers, customer data and payments.
- [ ] Replace real records with clearly identified **synthetic sample data**.
- [ ] Verify image rights for every icon, background, product photo and third-party visual.
- [ ] Save a source capture before adding labels or cropping. Record capture date, build/commit and screen route.
- [ ] Publish a compressed WebP/PNG with descriptive alt text and caption identifying the product's actual status.
- [ ] Check appearance on narrow mobile screens and high-density displays.
- [ ] Do not promote a debug screen or untested feature as a stable release.

## 2. Real walkthrough videos

- [ ] Record a real application build at 1080p, readable fonts, approximately 45–90 seconds.
- [ ] Use a clear story: problem → demonstrated action → result → verification.
- [ ] Avoid fake demos, fabricated testimonials or speeded-up processing presented as real-time.
- [ ] Mute or replace potentially sensitive audio and notifications.
- [ ] Provide captions/transcript, pause controls, a poster image and a video file with reasonable file size.
- [ ] Verify ownership and copyright permission for all audio/video assets.
- [ ] Consider a no-audio silent demo if the value comes from visual UI behavior.
- [ ] Include proof of the build/commit or environment used without leaking secrets.

## 3. Finished client sites

- [ ] Document work done personally, scope, tools, client constraints and dates.
- [ ] Record performance/SEO improvements only after measuring them, including methodology.
- [ ] Never publish clients' private business results or personal data without permission.
